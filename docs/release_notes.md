# 版本说明

## 0.2.0 · 2026-11-15

0.2.0 同时提供原生桌面工作台和命令行。桌面目标为 Windows 11 x64 和 Ubuntu 22.04 / 24.04 x64（X11 / XWayland）；常规源码构建提供 CPU 路径，CUDA、ONNX 和 CGAL 按构建启用。Linux 桌面包以 Ubuntu 22.04 为兼容基线。

- 工作台管理照片、工程和阶段结果，支持逐节点调参、重跑和浏览产物。暂停在当前计算子步骤完成后生效。
- 可选 ALIKED 和 LightGlue 需要 ONNX Runtime 以及另外取得的模型权重。默认包不承诺提供学习型模型、Delaunay、多 GPU、GIS/GCP 编辑和算法内部暂停。
- COLMAP 互通覆盖稀疏 BIN/TXT 和文档所列稠密文件；离线桥接工具负责特征、匹配以及支持字段的几何交换。
- 桌面默认深度图宽、高各减半，保留去畸变原分辨率供纹理映射。显式保存的旧工程参数保留。较大的旧产物可以查看缩减后的预览，并仍按原始文件导出。

### 验证范围

此前本地在 Windows 原生及 Ubuntu（WSL）验证过桌面构建和重建流程。House 示例用 Windows CUDA 后端处理 36 张照片，全部注册，生成 2,243,803 个稠密点和 312,820 个三角形；本次计算约 22 分钟。这是该机器和参数下的实际结果，不能用于预测其他数据或硬件的耗时。

正式二进制应从 `v0.2.0` 对应提交重建并附上校验值。全新 Windows 系统验收仍是二进制公开分发的门槛；开发机验证不等同于全新系统验收。数据集、模型权重和演示工程不随源码仓库分发。

### 已知限制

全局式和分层式稀疏重建仍需更广泛的数据验证。COLMAP 文件格式互通不意味着同照片集上有相同的注册率、精度或纹理。重建占用空间主要受照片数、深度图分辨率、中间图和图集尺寸影响；磁盘中保留的历史计算结果需由用户管理。

## 0.1.0 · 2026-08-10

原始 Alpha CLI 源码快照，包含增量式稀疏重建、COLMAP 模型读写、CPU / CUDA SIFT 和 PatchMatch、点云、网格及纹理。其安装方法、文档和支持范围以 `v0.1.0` 标签中的内容为准；没有 GUI 或 0.2 的工作台工程格式。
