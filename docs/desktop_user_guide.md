# Colite 桌面使用说明

## 开始一个工程

启动后是未命名工程，无需先创建 JSON。左侧工作区下方可“添加照片”或“添加文件夹”；文件夹递归读取 JPEG/PNG，并保留相对目录。重复的同一文件不会重复添加；不同来源的同名照片应按文件夹添加以保留分组。

默认工作目录为可执行程序所在目录下的 `output`，可在参数窗口底部直接编辑，或用“更改…”选择目录；“文件 → 项目数据”也保留此入口。首次计算自动创建独立 `runs/<uuid>` 目录，管理特征、匹配、稀疏、稠密、网格和纹理产物。不要逐个修改这些产物路径。

- 第一次直接添加文件夹时，程序引用该目录，不复制原图。
- 单独添加照片或混合多个来源时，首次计算会把选择的照片复制到工作目录下的 `photos-*`，形成计算输入快照。准备过程可取消。
- 之后修改外部原图不会自动更新已复制的快照。要更换输入，请重新选择数据源或添加照片，再运行流程。
- 添加新照片或更换数据源会分配新的计算输出位置，旧结果仍保留。数据盘容量需同时考虑原图副本、深度图和模型；照片准备的空间检查不是整条重建流程的容量保证。

## 保存、另存为与搬迁

“保存项目”保存 `.colite.json`，其中记录照片引用、工作目录、参数和界面状态，**不把照片或模型打包到 JSON**。程序为未保存更改保留独立恢复草稿；异常退出后可选择恢复，恢复后仍需显式保存。取消恢复会保留记录。

“文件 → 最近工程”列出最近打开或保存的五个工程，重启后仍可从这里打开。同名工程显示文件路径，已移动或删除的记录可从菜单移除。

“工程另存为”保存同一工程的另一份描述文件，保留工程 ID、工作目录和计算结果，**不是独立复制整个工程**。需要独立重建时，新建工程并选择单独工作目录。

搬迁工程时一起移动工程文件、输入照片和工作目录，并保留它们之间的相对位置。原图目录丢失时，使用“文件 → 项目数据”重新定位。不要仅移动 JSON 后删除原工作目录；运行中的工程目录也不应移动。

## 运行与复用

顶部依次为图像、特征提取、特征匹配、稀疏重建、稠密重建、表面重建、纹理映射。点击节点查看内容；顶部“参数”自动定位当前节点，也可右键节点选择配置参数。选择“保存参数”仅修改配置；选择“运行节点”（已有结果时显示“重新运行节点”）使用当前页更新后的参数计算当前节点，适合逐步调参。

右上角“参数”按流程分页展示全部配置；“启动”不弹出参数窗口，直接从当前节点运行到纹理；选中图像时从特征提取开始。参数窗口也可勾选继续运行后续节点。图像页包含相机分组和全流程计算设备，照片路径在“项目数据”中管理。工作目录固定显示于参数窗口底部，切换流程页时保持可见；保存新工作目录将分配新的结果目录并保留原文件，需要从特征提取开始运行。取消不会修改工程。未修改的参数不会因浏览其他页而改变。运行期间参数入口不可编辑。

节点以图标与颜色表达状态，不显示常驻状态文字：绿色线条圆圈加对勾表示完成，旋转圆弧表示运行或校验，灰色空圈表示待运行，时钟表示排队，橙色感叹号表示待更新，暂停双线表示已暂停，方块表示已中止，红色叉号表示失败，问号表示待核验。悬停可查看详细状态，读屏也可获取状态描述。浅绿背景和底部实线表示当前选择，不显示虚线框。输入、参数或产物变化后，过期阶段需要重算。旧工程没有有效性记录时会显示未核验，不等于已确认与当前参数一致；需要确定可复现结果时，从相应上游阶段重新运行。

稀疏重建出现多个子模型时，可在左侧选择要继续处理的模型；稠密阶段使用当前选择。属性中的注册/未注册照片数用于判断重建覆盖范围。

“步后暂停”在当前计算子步骤完成后暂停后续队列；不会立即冻结当前算法。“中止”结束本次计算进程，保留磁盘上的已有产物；再次启动时校验并按参数复用缓存。阶段计数表示当前子阶段的实际处理数，不代表整个工程已完成。未知进度显示活动条，不估算百分比。

## 算法与参数

流程名称统一为“图像导入、特征提取、特征匹配、稀疏重建、稠密重建、表面重建、纹理映射”。每页先展示常用参数，其余项目放在可展开的“高级参数”中。切换算法只展示并传递适用参数，其他算法的已填设置保留，切换回来可继续使用。

| 页面 | 常用选项 | 高级选项示例 |
| --- | --- | --- |
| 图像导入 | 相机模型、相机分组、计算设备 | 手动内参、焦距估计系数、逐图／公共遮罩 |
| 特征提取 | SIFT／ALIKED N16Rot／ALIKED N32、图像尺寸、特征数量、检测阈值 | SIFT 实现、尺度、方向、归一化、推理设备、线程数 |
| 特征匹配 | 穷举／序列／空间配对、暴力匹配／LightGlue | 比值／距离／置信度、几何验证、引导匹配、线程数 |
| 稀疏重建 | 增量式／全局式、内参优化、重投影误差 | 增量初始化与局部 BA；全局旋转平均与位置估计；三角化和全局 BA |
| 稠密重建 | 深度图尺寸、几何一致性、迭代次数、融合支持数 | 去畸变尺寸、窗口半径、NCC、重投影／深度／法线过滤 |
| 表面重建 | Poisson／Delaunay、网格简化 | 点权重、顶点颜色、正则化、边界保留、线程数 |
| 纹理映射 | 纹理比例、最大图集边长、颜色校正 | 视图平滑、图块边距、补洞、可见性分辨率 |

GUI 默认按每张去畸变图像宽高的 50% 估计深度，并使用 Poisson 深度 9。去畸变图默认保留原分辨率供纹理映射使用。深度图尺寸也可填正整数指定最长边，或填 `-1` 使用原尺寸。已有工程明确保存的数值继续保留。默认值变更可能让相关节点显示待更新，仍可查看旧模型；从第一个待更新的节点重算即可。

ALIKED／LightGlue 需要支持 ONNX 的引擎及模型文件；程序自动查找安装根目录的 `models/`，也可在对应参数页选择模型。模型推理设备独立于图像页的 SIFT／稠密计算设备。CPU ONNX Runtime 与 SIFT／稠密 CUDA 相互独立，可以在同一个构建中使用。Delaunay、学习型特征和学习型 CUDA 按随包引擎的实际能力启用，未包含的选项不可选。全局式重建从已有特征与匹配重新求解，不用于续接已有稀疏模型。

## 查看和导出

3D视图支持点云、相机、网格和纹理；左拖旋转、右拖平移、滚轮缩放、F 适配。表面和纹理在交互中保持连续显示。加载进度在底部显示。CPU/GPU 缓存改善重复切换；首次读取仍取决于模型和磁盘大小。网格预览预算为 1 GiB；尺寸过大时可用缩减预览，属性区标明显示量。无法读取或建立预览时仍可导出已通过校验的原始模型。

2D视图包括照片、特征点和特征匹配。选择照片设为当前图像，Shift 选择另一张照片配对；匹配视图可区分几何内点与其他匹配。特征点默认显示上限为 10,000，特征匹配默认显示上限为 2,000，可分别调整。预览最长边缩放至 4096，特征坐标仍对应原图。

右侧标签栏可切换“照片”和“日志”；运行或失败时自动显示日志，取消“跟随最新”可停留在历史内容。“打开文件”可查看完整任务日志。左下角“属性”合并属性和统计，随照片、相机或模型选择更新。外部模型和 PLY 的加载入口位于“工具”菜单；顶部工具栏依次提供 3D视图、2D视图、适配视图。

“文件 → 导出当前模型”写入一个新的目录。稀疏模型导出 COLMAP 文件，点云/网格导出 PLY，纹理随模型一起复制。目标目录已存在时不会覆盖；失败或取消不会留下已提交的半成品。

## 失败后如何继续

任务条的“错误详情”给出原因和建议，“打开日志”保留完整后端输出。空间不足时释放工作磁盘空间；无法写入时检查目录权限；内存不足时降低图像尺寸或并发线程数；CUDA 不可用时可选择 CPU。修正原因后从失败阶段重试，若提示前置产物过期，则从提示的上游阶段开始。

不要通过删除原始照片或正在使用的工作目录解决错误。历史运行产生的旧 `runs/*` 和照片快照不会自动清理；确认没有工程引用并备份所需结果后，再自行清理。

## 平台与发行包

Windows 使用原生 `colite_gui.exe`，Linux 使用原生 `colite_gui`；程序自动调用随包算法引擎，无需配置 WSL 或后端路径。CPU 包不需要 NVIDIA 显卡；CUDA 版适用范围取决于包的构建架构和驱动；已验证配置见[版本说明](release_notes.md)。

目标桌面平台为 Windows 11 x64、Ubuntu 22.04/24.04 x64 的 X11/XWayland。若安装目录只读，在首次运行前将工作目录改到用户可写位置。默认包覆盖 JPEG/PNG、常规 SfM、稠密、Poisson 和纹理；ONNX、CGAL、GIS/GCP 编辑和算法内部暂停不属于默认包范围。

反馈问题时附“帮助 → 关于 Colite”的版本/源码信息、操作步骤和对应任务日志。程序不会自动上传工程、照片或日志。
